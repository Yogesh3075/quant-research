# Phase 3 pre-registration (committed before any Phase 3 run)

- Base: Phase 1 put spread (sell put nearest 0.95 S0, buy put nearest 0.90 S0, max loss 10% of capital), Phase 2 fallback rule for illiquid strikes. Costs, cash rate 6.5%, split as Phase 2: design = entries 2008-01 to 2018-12 (132 cycles); validation = entries 2019-01 to the cycle expiring 2024-10-31 (69 cycles), run once. Holdout not loaded.
- Trials 10-12 (cumulative 12): **e1** stop-loss, **f1** premium filter, **e1f1** both. References (not trials): base and NIFTY 50 TRI buy-and-hold.
- **E1:** each trading day's close after entry, mark both legs at bhavcopy close (missing close: carry the last one). If MTM loss (from the entry fill prices) >= 2 x net credit received (after entry slippage), close both legs at the next trading day's close with slippage and all charges; if a leg has no close that day, use the next day it has one (flagged). A trigger on the day before expiry (or later) is ignored: the position settles normally. Cash until the next regular entry.
- **F1:** gap = ATM implied vol at entry (Phase 1 method: strike nearest S0, mean of call and put Black-Scholes IV, r 6.5%, no dividend) minus realised vol of NIFTY 50 over the previous 21 trading days (21 daily log returns ending at the entry close, x sqrt 252). Trade only if gap > threshold = median of the gap over all earlier entry dates from 2008 on (expanding; in validation this includes earlier validation entries, using only data known at that entry). Needs at least 24 earlier cycles with a gap; trade every month before that. Cycles with no gap: trade (logged).
- **Choice (design only):** keep a variant only if its design option-only Sharpe beats the base **and** its worst month and CVaR 99% are no worse than the base's. If several qualify, the highest Sharpe. If none, the frozen rule is the base put spread. Committed in `results/phase3/choice.md` before validation.
- After Phase 3 the rule set is frozen (`results/phase3/frozen_rule.md`).
